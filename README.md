# What Is MarketerBrowser?

MarketerBrowser is an anti-detect browser and browser-profile management platform built around isolated browsing environments.

Instead of using one browser environment for everything, you can create separate profiles for different accounts, projects, websites, testing environments, or workflows.

Each profile can maintain its own:

* Browser cookies
* Local storage
* Session data
* Proxy configuration
* User agent
* Time zone
* Geolocation
* Canvas environment
* WebGL environment
* Audio environment
* Font configuration
* Screen configuration
* Browser settings

The goal is simple:

> **Keep different browser environments separated and manageable.**

# 🔐 Browser Fingerprinting

Browser fingerprinting is the process of identifying characteristics of a browser and its surrounding environment.

A fingerprint can contain many different signals.

## Common Fingerprint Signals

### Canvas Fingerprinting

Websites can use the HTML5 Canvas API to generate characteristics that may differ between browser environments.

Learn more:

* [Canvas Fingerprinting](docs/canvas-fingerprint.md)

### WebGL Fingerprinting

WebGL can expose information related to the browser's graphics environment and GPU configuration.

Learn more:

* [WebGL Fingerprinting](docs/webgl-fingerprint.md)

### Audio Fingerprinting

Browser audio APIs can expose characteristics that contribute to a browser fingerprint.

Learn more:

* [Audio Fingerprinting](docs/audio-fingerprint.md)

### Font Fingerprinting

The fonts available to a browser environment can provide additional information about the environment.

Learn more:

* [Font Fingerprinting](docs/font-fingerprint.md)

### WebRTC

WebRTC can expose network-related information depending on browser and network configuration.

Learn more:

* [WebRTC and Browser Fingerprinting](docs/webrtc-fingerprint.md)

### Screen and Display Information

Screen size, resolution, device pixel ratio, and related browser properties can contribute to fingerprinting.

# 🌐 Proxies and Browser Profiles

A proxy changes the network path used by a browser.

However, a proxy alone does not create an independent browser environment.

A complete browser profile may involve both:

**Network identity + browser environment + session data**

MarketerBrowser supports HTTP and SOCKS proxy configurations for browser profiles.

# 🧩 CAPTCHA and Browser Detection

CAPTCHA challenges are influenced by many factors.

They can be associated with:

* Traffic patterns
* IP reputation
* Browser signals
* Session behavior
* Website-specific risk systems
* Automated traffic detection

An anti-detect browser should not be treated as a guarantee that CAPTCHA challenges will never appear.

Instead, browser environments, network configuration, session consistency, and normal browsing behavior should be considered together.
